# Démarrage rapide

## Créer et ouvrir
| Action | Raccourci |
|---|---|
| Nouveau document | `Ctrl+N` |
| Ouvrir | `Ctrl+O` ou glisser-déposer |
| Enregistrer | `Ctrl+S` |
| Palette de commandes | `Ctrl+Maj+P` |

## Sécurité de vos données
1. L'**auto-save** attend que vous cessiez d'écrire (jamais à chaque frappe).
2. Une **copie de sauvegarde** est conservée avant chaque écrasement.
3. Après un plantage, les documents non enregistrés sont **récupérables**.
4. Un fichier modifié par un autre programme n'est **jamais écrasé en silence**.
