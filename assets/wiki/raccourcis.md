# Raccourcis clavier

Tous les raccourcis sont modifiables dans **Paramètres › Raccourcis** (détection des conflits).

## Fichiers
`Ctrl+N` nouveau · `Ctrl+O` ouvrir · `Ctrl+S` sauvegarder · `Ctrl+Maj+S` sauvegarder sous · `Ctrl+W` fermer l'onglet · `Ctrl+Maj+T` rouvrir

## Édition & recherche
`Ctrl+Z` / `Ctrl+Y` annuler / rétablir · `Ctrl+F` rechercher · `Ctrl+H` remplacer · `F3` suivant

## Markdown
`Ctrl+Maj+M` aperçu Markdown · `Ctrl+B` gras · `Ctrl+I` italique

## Développeur
`Ctrl+Maj+L` console de logs · `Ctrl+Maj+I` DevTools
