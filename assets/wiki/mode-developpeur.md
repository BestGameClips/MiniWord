# Mode développeur

Activez-le dans **Paramètres › Avancé › Mode développeur**.

- **Console de logs** (`Ctrl+Maj+L`) : flux en temps réel, coloré — 🟢 succès, 🟡 avertissements, 🔴 erreurs.
- **Outils de test** : générer des logs de test, copier le diagnostic, forcer la reconnexion Discord.
- **Numéros de ligne** : option dans Paramètres › Éditeur.
- **Administration du Wiki** : création, édition et suppression de pages.
