# Dépannage

## Discord n'affiche rien
- Lancez l'**application de bureau** Discord (pas le navigateur).
- Vérifiez le *Client ID* dans **Paramètres › Discord** (pastille verte = connecté).

## Le wiki ne se met pas à jour
Cliquez sur **↻ Recharger**. Hors ligne, la version en cache est utilisée.

## Windows SmartScreen
L'installateur n'est pas signé : choisissez *Informations complémentaires › Exécuter quand même*.
