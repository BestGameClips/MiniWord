# Bienvenue dans le Wiki MiniWord

MiniWord est un traitement de texte **léger, rapide et hors ligne**. Ce wiki est livré avec l'application, et se synchronise avec GitHub quand un dépôt est configuré.

- [Démarrage rapide](#) : créer, ouvrir, enregistrer
- Les pages de la barre de gauche couvrent les raccourcis, Discord, le mode développeur et le dépannage.
- Le bouton **↻ Recharger** force la mise à jour des pages depuis GitHub.

> Astuce : tapez `/md` dans la palette de commandes (`Ctrl+Maj+P`) pour prévisualiser n'importe quel fichier Markdown.
